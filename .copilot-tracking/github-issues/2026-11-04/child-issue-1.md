## 요약

승인된 근거 경계를 강제하고, 분석이 시작되기 전에 무단이거나 신뢰도가 낮은 입력을 거부하는 워크플로우를 구현합니다.

## 범위
- 허용된 근거 루트와 데이터 입력 정의
- 승인되지 않았거나 민감한 소스 거부
- 데이터를 사실, 추론, 가정, 미확인으로 분류
- 승인 또는 권한이 없으면 접근 차단

## 수용 기준
- [ ] 처리 시작 전에 승인된 근거 소스가 정의된다
- [ ] 무단 또는 지원되지 않는 입력이 차단된다
- [ ] 시스템이 근거 모델에서 사실과 가정을 구분한다
- [ ] 데이터가 없거나 제한된 경우 사용자에게 명확한 메시지를 표시한다
