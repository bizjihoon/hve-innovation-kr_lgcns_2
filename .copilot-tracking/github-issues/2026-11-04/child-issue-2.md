## 요약

경영 질문을 수집하고, 관련 승인된 데이터 소스를 식별하며, 요약을 생성하기 전에 검토 컨텍스트를 확보합니다.

## 범위
- 제한된 워크플로우에서 비즈니스 질문 수용
- 질문을 승인된 근거 소스에 매핑
- 누락되거나 지원되지 않는 정보 조기 식별
- 권고를 생성하기 전에 가정이나 제약 사항을 드러냄

## 수용 기준
- [ ] 워크플로우가 의사결정 맥락과 적절한 시간 범위를 물어본다
- [ ] 승인된 근거 경계에서 관련 소스가 식별된다
- [ ] 지원되지 않거나 누락된 데이터가 명확히 플래그된다
- [ ] 사용자가 유효한 질문과 지원되지 않는 질문을 구분할 수 있다
