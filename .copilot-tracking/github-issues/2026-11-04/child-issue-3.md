## 요약

승인된 근거와 명확한 근거 구분을 바탕으로 경향, 예외, 미해결 질문을 요약하는 간결한 경영 브리프를 생성합니다.

## 범위
- 핵심 지표와 이상치 요약
- 경영 검토에 관련된 예외와 추세 변화를 표시
- 브리프에서 사실, 가정, 불확실성을 분리
- 출력이 경영진이 읽고 검토하기 쉽도록 유지

## 수용 기준
- [ ] 결과물에 발견 사항과 예외를 포함한 짧은 요약이 포함된다
- [ ] 사실과 가정이 명시적으로 분리된다
- [ ] 불확실성과 누락된 근거가 명확히 드러난다
- [ ] 요약에 소스 참조 또는 승인된 데이터 이름이 유지된다
