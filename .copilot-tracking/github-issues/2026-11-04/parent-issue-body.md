## 요약

관계 관리자 / 경영관리 분석 에이전트의 첫 MVP를 구축합니다. 이 에이전트는 관리자가 승인된 운영 근거를 검토하고, 예외를 요약하며, 어떤 조치도 취하기 전에 불확실성을 드러내도록 돕습니다.

## 배경

이 상위 이슈는 워크숍 시나리오의 첫 릴리스 슬라이스를 정의하며, 승인된 PRD와 백로그 계획에 맞춰 정렬됩니다. MVP는 자율적 의사결정 대신 근거 기반 검토 지원과 인간 에스컬레이션에 의도적으로 제한됩니다.

## 범위
- 승인된 근거만 검토하고 요약한다
- 예외, 추세, 누락된 맥락을 식별한다
- 사실, 가정, 미해결 질문을 분리한다
- 조치 전 인간 검증을 요구한다

## 수용 기준
- [ ] 분석이 시작되기 전에 승인된 근거 경계를 강제한다
- [ ] 소스 인식형 경영 질문을 검토 가능한 워크플로우로 답변할 수 있다
- [ ] 출력이 사실, 추론, 가정, 불확실성을 구분한다
- [ ] 위험하거나 지원되지 않는 결론에는 인간 검토가 필요하다
- [ ] MVP는 워크숍 안전한 의사결정 지원 워크플로우에만 범위를 제한한다
